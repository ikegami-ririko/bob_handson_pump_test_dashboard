## 全体の流れ

1. 初期開発：Plan モードで計画を作成し、ダッシュボードの初期バージョン（HTML）を作成する
2. 機能開発：Agent モードでラベルデータの内訳を可視化し、タブ機能を追加する

## 1. 初期開発

### 1.1 リソースの準備

リソースのzipファイルをダウンロードして展開する。（場合によってはデスクトップなど作業しやすい場所へ移動）。
Bobを起動し、該当ファイルを開く。

### 1.2 初期バージョンの作成（Plan モード）

Plan モードで、以下のプロンプトを入力する。

```text
あなたはフロントエンドエンジニアです。@data/pump_test_measurements.csv より「ポンプ試験データ分析ダッシュボード」の初期バージョンを作成してください。
```

### 1.3 要件のヒアリング

Bob からの質問に、以下のとおり回答する。

| 項目 | 回答 |
| --- | --- |
| データ読み込み | ファイルインポートを指定 |
| 対象機能 | 一覧表、サマリーカード、グラフ |
| 対象データ | T1〜T30 すべて|

### 1.4 計画の作成と実装

1. Bobが「ポンプ試験データ分析ダッシュボード計画」を作成する
2. BobがHTMLなどのファイル群を作成する

## 2. 機能開発

### 2.1 事前準備

`.bobignore` の中のdata/pump_test_labels.csvを削除し、保存。

### 2.2 ラベルデータの可視化とタブ機能の追加（Agent モード）

新しいセクションを開始し、Agent モードで、以下のプロンプトを入力する。

```text
@data/pump_test_labels.csv を読み込んで、内訳を視覚化するダッシュボードを作成してください。また、ダッシュボードに複数のタブ機能を実装してください。
```
